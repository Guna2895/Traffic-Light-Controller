
# Traffic Light Controller

## Description
A simple Arduino-based traffic light controller that controls
Red, Yellow, and Green LEDs using programmed timing sequences.

## Components
- Arduino
- Red LED
- Yellow LED
- Green LED
- Resistors
- Connecting wires

## Features
- Automatic traffic light sequence
- Simple Arduino control
- Timed switching of traffic signals

## Program
The Arduino program is available in `TrafficLight.ino`.
